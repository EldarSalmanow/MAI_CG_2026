# Устройство шейдеров ЛР №1–3

Шейдеры организованы процедурно. Начинать чтение удобно с `shader.frag`:
он читает материал, рассчитывает освещение и прибавляет текстурное свечение.

| Файл | Назначение |
|---|---|
| `shader.vert` | Преобразование позиции и нормали, передача цвета и UV |
| `shader.frag` | Последовательность от материала до итогового цвета |
| `material.glsl` | Чтение текстур и параметры материала |
| `lighting.glsl` | Блинн–Фонг и затухание источников света |
| `scene_interface.glsl` | Uniform-блоки с теми же полями и смещениями, что в C++ |

## Материал и текстуры

`sampleTextures(uv)` читает albedo, specular и emissive по одинаковым UV.
Чёрная дополнительная карта обнуляет соответствующий эффект.

`sampleAnimatedTextures(uv, time)` реализует дополнительное задание ЛР №3:

1. Первый слой движется вдоль U.
2. Второй слой движется вдоль V, его UV умножены на 2.
3. Две выборки каждой карты смешиваются с весом `blendWeight`.
4. Альбедо умножается на плавно меняющийся цвет:
   `mix(white, pulseTint, 0.5 + 0.5 * sin(time))`.

Карты используют одинаковые UV, поэтому блик и свечение следуют рисунку.
Волновых деформаций, независимых цветовых фаз и других эффектов нет.
Это несколько чтений текстуры; к MSAA данный эффект не относится.

`sampleMaterial(uv, vertexColor)` применяет повторение UV, выбирает режим
по `animationEnabled`, затем учитывает tint объекта, цвет вершин и силу
свечения. В обычном режиме каждая карта читается один раз, в анимированном — два.

`SamplingParameters` занимает 32 байта и совпадает с C++ `SamplingPushConstants`:

| Поле | Смещение |
|---|---:|
| `tiling` | 0 |
| `time` | 8 |
| `speed` | 12 |
| `blendWeight` | 16 |
| `animationEnabled` (`uint`) | 20 |
| `emissionStrength` | 24 |
| `reserved` | 28 |

Скорость 0 замораживает сложный режим. Чтобы получить обычное чтение текстуры,
нужно выключить `Animated sampling`. Настройки передаются через push-константы,
а не добавляются в uniform-буфер модели.

## Освещение

`Surface` содержит мировую позицию, нормаль и направление к камере.
`LightSample` содержит направление к свету и его яркость с учётом затухания.

- `blinnPhong(surface, material, light)` рассчитывает диффузную и зеркальную части.
- `sampleLocalLight(offset, radiance)` учитывает закон обратных квадратов.
- `spotlightAttenuation(cosine, innerCosine, outerCosine)` формирует край конуса.
- `sampleSpotLight(light, position)` сочетает угловое и дистанционное затухание.
- `evaluateLighting(surface, material)` суммирует ambient и все источники.

`material.emissiveColor` прибавляется после освещения. Он делает поверхность
видимой в темноте, но не освещает соседние объекты.

`object.unlitColor` — отдельный постоянный цвет маркеров света и каркасов конусов.
При флаге `object.unlit` шейдер сразу возвращает его, обходя текстуры и освещение.

## Двоичный интерфейс

Именованные поля C++ и GLSL соответствуют друг другу. Uniform-буферы используют
`std140`, storage-буферы — `std430`. Флаги хранятся в `std::uint32_t`/`uint`.
В `gpu_data.hpp` проверяются размеры и смещения полей.

Матрицы и параметры освещения остаются в UBO; настройки сэмплирования находятся
в push-константах. Номера descriptor set/binding сохранены. Шейдеры компилирует
CMake через существующую функцию `compile_shader`.
